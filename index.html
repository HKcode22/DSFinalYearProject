Startup Funding Stage Prediction & Market Analysis

Bay Area Focus

Project Overview

This project focuses on predicting startup funding stages for Bay Area companies using machine learning.

The current live application is deployed on Google App Engine and available at:

View Live Application

Key Features

  • Funding Stage Prediction: Predicts Seed, Series A, Series B stages based on company metrics
  • Bay Area Market Analysis: Focused on San Francisco Bay Area startup ecosystem
  • Anomaly Detection: Flags unusual company data patterns
  • Time Series Forecasting: Market trend predictions for Bay Area funding
  • Interactive Dashboard: User-friendly interface for predictions and insights

Technology Stack

Backend
  • Python 3.11+
  • Machine Learning (scikit-learn, XGBoost, LightGBM)
  • Data Processing (pandas, numpy)
  • Web Scraping (Selenium)
Frontend
  • Dash (Python web framework)
  • Plotly for visualizations
  • Bootstrap for styling
  • Google App Engine deployment

Data Sources

Bay Area startup data is collected from:

  • GrowthList.co
  • TopStartups.io
  • FundraiseInsider.com
